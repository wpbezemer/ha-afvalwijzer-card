# Afvalwijzer Card  Mooie Lovelace card voor ophaaldata van afvalfracties met urgentie-indicatoren, automatische sortering en visuele editor.  Getest en ontwikkeld op basis van de [homeassistant-afvalwijzer](https://github.com/xirixiz/homeassistant-afvalwijzer) integratie van [@xirixiz](https://github.com/xirixiz).
